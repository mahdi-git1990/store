# فروشگاه با Bootstrap (صفحه اصلی و صفحه محصول)

این پروژه شامل طراحی صفحه اصلی و صفحه محصول یک فروشگاه اینترنتی است که با استفاده از فریم‌ورک Bootstrap پیاده‌سازی شده است.

## هدف پروژه
- طراحی رابط کاربری جذاب و واکنش‌گرا (Responsive) برای صفحه اصلی فروشگاه.
- طراحی صفحه جزئیات محصول با نمایش اطلاعات کلیدی.
- استفاده بهینه از کامپوننت‌های Bootstrap برای سرعت بخشیدن به توسعه.

## تکنولوژی‌های استفاده شده
- HTML5
- CSS3
- Bootstrap 5 
- JavaScript

## ساختار فایل‌ها
- `assets/`: پوشه‌ای شامل:
    - `css/`: فایل‌های CSS 
    - `img/`: تصاویر محصولات و المان‌های گرافیکی
    - `js/`: کد های js
    -  `font/`: فونت‌های استفاده شده
- `index.html`: صفحه اصلی
- `product-single.html`: صفحه محصول

## نحوه اجرا
1.  برای صفحه اصلی فایل index.html و برای صفحه محصول فایل product-single.html  را باز کنید.
